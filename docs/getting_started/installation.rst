Installation
============

Requirements
------------

SpectraLog requires Python 3.10 or later.

Install from PyPI
-----------------

Install the latest released version with pip:

.. code-block:: bash

   python -m pip install spectralog

Verify the Installation
-----------------------

After installation, verify that SpectraLog can be imported:

.. code-block:: python

   import spectralog

Development Installation
------------------------

Clone the repository and install the package in editable mode:

.. code-block:: bash

   python -m pip install -e .

Documentation Dependencies
--------------------------

Install the documentation dependencies with:

.. code-block:: bash

   python -m pip install -e ".[docs]"

The documentation can then be built with Sphinx.
